# 마이펫에서 AI와 나눈 일

## 기획과 구현

제가 정한 목표는 보호자마다 다른 생활 시간에 맞춰 강아지와 지낼 수 있게 하는 것이었습니다. 세부 행동 규칙과 구현은 에이전트에 위임하고 실제 플레이를 보고 다음에 무엇을 고칠지 정했습니다. ChatGPT로 조사와 그림 시트를 준비했고, Claude Code와 Codex로 앱 코드와 테스트를 만들었습니다.

시간에 따라 달라지는 행동을 하루씩 기다리며 검증하기 어려워 10월 2일에 연습 시계를 요청했습니다. 별도 연습 펫으로 밥을 준 뒤 시계를 다음 날 아침으로 옮기면, 같은 조건에서 첫 재회와 기록을 다시 확인할 수 있습니다. [연습 시계와 화면 흐름 검사](../test/test_mode_flow_test.dart)

## 구현과 독립 검토

제출 준비 때는 원본과 분리된 복제본에서 Claude Code가 전체를 점검하고, Codex가 현재 코드에서 지적을 재현한 뒤 수정하도록 제가 일을 나눴습니다. Claude Code는 첫 재회 말풍선이 약 2초 뒤 오늘의 소원에 덮인다는 사실을 발견했습니다. Codex는 소원 안내를 미루고 밥과 공놀이 두 조건에서 재회 문장이 6초 동안 보이는지 검사한 뒤 영상을 다시 만들었습니다. [첫 재회 회귀 검사](../test/first_day_recognition_test.dart)

S22 놀이 문제의 출발점은 제가 직접 누른 순서였습니다. 로그가 충분하지 않아 Codex에 터치, 실제 접수 명령과 다음 화면을 같은 입력 번호로 기록하도록 요청했습니다. [놀이 입력 확인 결과](play-verification.md)

## 반복 작업

원래 작업 환경에서는 되풀이하는 절차를 스킬로 등록했습니다. `build-batch`는 기능 구현 뒤 검사·리뷰·보고를, `run-device`는 ADB 설치·입력·화면 캡처를 다룹니다. 검토 에이전트에는 파일 수정과 분리해 재현 조건과 판단 근거를 보고하도록 했습니다. 다음 작업자가 이어받을 수 있게 Markdown에 완료한 검사와 남은 항목을 남겼습니다. GitHub Actions에서는 연습 시계와 재회 시나리오, 2주 모의실험, 전체 테스트를 실행합니다. [검사 단계](../.github/workflows/pet-care.yml)
