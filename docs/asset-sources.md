- 기본 강아지 그림은 ChatGPT로 생성한 시트에서 포즈를 나누고 앱의 픽셀 규격에 맞췄습니다. 시연 영상에는 앱 화면과 프로젝트에서 합성한 효과음을 사용했습니다.
- 사진 관련 테스트용 이미지는 재현 가능한 합성 견본입니다. [견본 생성 코드](../tools/scene_preview/fixtures/generate_photos.py)
